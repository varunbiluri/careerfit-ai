# Research data (Day 1 output)

Generated by `backend/scripts/research_day1_data.py`.

| File | Description |
|------|-------------|
| **synthetic_resumes.json** | 50 synthetic resumes; each has `resume_id` and `skill_names` (5–15 skills from `skills_dictionary.json`). |
| **job_corpus.json** | Jobs from DB (up to 200) with `job_id`, `title`, `company`, `skill_names`. If DB has fewer than 200 jobs, run "Analyze Skills Gap" to scrape more, then re-run the script. |
| **skill_demand.json** | Demand φ(s) = (number of jobs containing skill s) / total_jobs. Keys are skill names; values in [0, 1]. Sorted by demand descending. |

**Re-run Day 1:**

```bash
cd backend
uv run python scripts/research_day1_data.py
```

Used by the DW-SSGI paper experiments (Day 2–5).
