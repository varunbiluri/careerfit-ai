# Security Policy

## Reporting a Vulnerability

Please do not publish security issues publicly before they are triaged. Report suspected vulnerabilities privately to the project maintainer with:

- A concise description of the issue.
- Steps to reproduce it.
- Potential impact.
- Any suggested fix or mitigation.

## Sensitive Data

CareerFit AI can process resumes and job data. Avoid committing real resumes, personal information, API keys, database dumps, or `.env` files.
